# 管理費・修繕積立金 適正額シミュレーター

国土交通省「マンションの修繕積立金に関するガイドライン」（令和6年6月改訂）および
「令和5年度マンション総合調査」に基づく、管理費・修繕積立金の簡易試算ツールです。

単一HTML（ロゴ画像もbase64で埋め込み済み）で構成されており、ビルド作業は不要です。
マイソク読み取り時のみ、pdf.js（cdnjs）と Tesseract.js（jsDelivr）をその場で読み込みます。

## 主な機能

- **マイソク読み取り**：PDF・画像をドロップすると、築年月・地上階数・総戸数・専有面積・管理費・修繕積立金
  （＋記載があれば建築延床・機械式駐車場・物件名）を抽出して入力欄に自動反映
  - 文字入りPDFはテキスト抽出、画像だけのPDFや写真はブラウザ内OCR（日本語）で読み取り
  - ファイルは外部に送信せず端末内で処理（OCR用の日本語データのみ初回にダウンロード）
  - 自動入力した欄は黄色、読み取れなかった必須欄は赤枠で表示。平均専有㎡は対象住戸と同値で仮置き

- 建築延床面積（実数または推定）と地上階数からガイドラインの区分を判定し、修繕積立金の適正額を算出
- 機械式駐車場の機種別加算（区分経理の有無で分岐）
- 管理費の水準判定（※国の㎡単価目安は存在しないため、マンション総合調査からの推計）
- 築古かつ目安の下限未満の場合の加重警告（1994年以前築は重大アラート）
- 長期修繕計画から `Z＝(A＋B＋C)÷X÷Y` を直接計算する厳密判定と、繰入依存度 `C÷(A＋B＋C)` の表示
- A4横1枚での印刷、判定結果のテキストコピー

## ローカルで開く方法

`index.html` をブラウザで開くだけで動作します。サーバーは不要です。

```bash
# WSL / Linux
xdg-open index.html

# macOS
open index.html

# Windows
start index.html
```

ローカルサーバー経由で確認したい場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## 更新手順

`index.html` を新しいものに差し替えて push するだけです。
数分以内に GitHub Pages へ自動反映されます。

```bash
cd ~/dev/kanri-sim
cp /path/to/新しいkanri-tsumitate-sim.html index.html
git add index.html
git commit -m "シミュレーターを更新"
git push
```
