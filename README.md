# 管理費・修繕積立金 適正額シミュレーター

国土交通省「マンションの修繕積立金に関するガイドライン」（令和6年6月改訂）および
「令和5年度マンション総合調査」に基づく、管理費・修繕積立金の簡易試算ツールです。

単一HTML（ロゴ画像もbase64で埋め込み済み）で構成されており、ビルド作業は不要です。
マイソク読み取り時に pdf.js（jsDelivr の pdfjs-dist。日本語フォント用cMapを含むため cdnjs ではなくこちら）と
Tesseract.js（jsDelivr）をその場で読み込みます。

## 主な機能

- **マイソクを読み込むだけで判定**（手入力欄なし）
  - PDF・画像をドロップすると、築年月・地上階数・総戸数・専有面積・管理費・修繕積立金
    （＋記載があれば建築延床・機械式駐車場・物件名・所在地）を抽出して判定
  - **複数物件が連なったPDF**（レインズの図面一括ダウンロード `zmn_list_*.pdf` 等）は1ページ＝1物件として全ページ読み取り、
    複数ファイルの同時ドロップにも対応
  - 文字入りPDFはテキスト抽出（pdf.js）、画像だけのページは端末内OCR（Tesseract.js・日本語）。文字情報を優先し、足りない項目だけOCRで補う
  - 戸建・土地等のページは「対象外」として一覧に表示
  - ファイルは外部に送信しない（ライブラリとOCR用日本語データのみCDNから取得）
- 物件一覧（修繕積立金・管理費の判定バッジ付き）→ クリックで詳細表示
- 建築延床（記載値または 専有×戸数÷0.78 で推定）と地上階数からガイドラインの区分を判定し、修繕積立金の適正額を算出
- 管理費の水準判定（※国の㎡単価目安は存在しないため、マンション総合調査からの推計）
- 築古かつ目安の下限未満の場合の加重警告（1994年以前築は重大アラート）
- 選択中物件のA4横1枚印刷・テキストコピー、一覧のExcel用（TSV）コピー

## ローカルで開く方法

`index.html` をブラウザで開くだけで動作します。サーバーは不要です。

```bash
# WSL / Linux
xdg-open index.html

# macOS
open index.html

# Windows
start index.html
```

ローカルサーバー経由で確認したい場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## 更新手順

`index.html` を新しいものに差し替えて push するだけです。
数分以内に GitHub Pages へ自動反映されます。

```bash
cd ~/dev/kanri-sim
cp /path/to/新しいkanri-tsumitate-sim.html index.html
git add index.html
git commit -m "シミュレーターを更新"
git push
```

## 公開設定

- 公開ソース: `main` ブランチ / ルート（`/`）
